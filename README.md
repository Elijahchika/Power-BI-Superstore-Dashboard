## Project Overview
Developed an interactive Power BI dashboard to analyze sales, profit, customer segments, and regional performance using the Superstore dataset.

## Tools Used
- Power BI
- DAX
- Excel

## Key Features
- KPI Cards
- Sales Trend Analysis
- Regional Performance
- Category & Sub-category Analysis
- Interactive Filters
